# STUB

Голосовой тикет-борд для работы с нейронками. Надиктовываешь задачу, получаешь тикет и перетаскиваешь его в Claude, Codex или OpenCode: текст и картинки сами вставятся в окно. Распознавание речи работает на твоём компьютере.

*A voice ticket board for working with AI apps. Dictate a task, get a ticket, drag it into Claude, Codex or OpenCode, and the text and pictures paste themselves into the window. Speech recognition runs locally. The app has a Russian and an English interface.*

**[Скачать для Windows](https://github.com/qpsychocode/stub-releases/releases/latest/download/STUB-Setup.exe)** · [сайт и видео](https://stub-voice.vercel.app)

Установщик без цифровой подписи, поэтому Windows может предупредить: «Подробнее» → «Выполнить в любом случае». Дальше STUB обновляется сам.

## Что умеет

- **Голос.** Ctrl+N в окне, Ctrl+Alt+T из любой программы (меняются в настройках). Текст появляется сразу, его можно править прямо во время записи.
- **Модели.** Скачивание, выбор и обновление моделей распознавания в настройках, от 23 до 453 МБ.
- **Отправка.** Перетащи тикет на гнездо нейронки или за край окна STUB, прямо в нужное приложение. STUB вставит текст, проверит, что он дошёл, и запомнит, кто взял тикет.
- **Чат проекта.** Правый клик по вкладке проекта: выбери, в какой чат нейронки идут его тикеты. Пока это работает с боковой панелью Claude Desktop.
- **Терминалы.** Панель справа от доски: кнопки запускают Claude, Codex, OpenCode или обычный терминал в папке проекта (своей или склонированной с GitHub). Тикет перетаскивается прямо в терминал, Enter нажимаешь сам.
- **Картинки.** Ctrl+V скриншота или перетаскивание файла. В нейронку они уходят вместе с текстом.
- **Проекты.** У каждого своя вкладка и своя доска.
- **Лимиты.** Остаток на 5 часов и на неделю у Claude и Codex и время до обновления.
- **Данные.** Локальная база SQLite, история изменений, корзина и ежедневные копии: `%APPDATA%\STUB`.

## Лимиты Claude

Данные для шкал берутся со страницы использования claude.ai, это не публичный API. Для них нужен отдельный вход в окне STUB, сессия хранится только в профиле приложения. Если ответ окажется непонятным, STUB покажет «нет данных». Лимиты Codex читаются через сам `codex`, с его собственным входом.

## Из исходников

Нужны Windows и Node.js 22 или новее.

```bash
npm install
npm run dev
```

- `npm run typecheck`: проверка типов.
- `npm run dist`: установщик в `dist/`.
- `npm run release`: новая версия в [stub-releases](https://github.com/qpsychocode/stub-releases), откуда STUB берёт обновления. Нужен `gh` с правом записи.

Устройство приложения описано в [SPEC.md](SPEC.md), сайт лежит в `site/`.
